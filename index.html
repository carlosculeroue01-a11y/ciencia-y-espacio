Ciencia y Espacio

Esta aplicación automatiza la publicación de videos en el canal de YouTube Ciencia y Espacio, del mismo propietario.

Lo que hace:

  • Genera ideas de video a partir de tendencias y escribe el guion.
  • Genera la voz, las imágenes y el video, y lo sube al canal con la API de YouTube.
  • Lee estadísticas básicas del canal con la API de YouTube Analytics.

La aplicación es de uso personal: solo la usa el dueño del canal. No se comparten datos con terceros, no hay anuncios y no se vende información.
