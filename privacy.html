Política de privacidad — Ciencia y Espacio

Última actualización: 19 de noviembre de 2026.

Qué datos usa la aplicación

La aplicación usa la cuenta de Google del dueño del canal únicamente para:

  • Subir videos al canal de YouTube del propietario (permiso youtube.upload).
  • Leer estadísticas básicas del canal (permiso yt-analytics.readonly).

No se recopilan datos de otros usuarios, porque la aplicación solo la usa el dueño del canal.

Cómo se guardan los datos

El token de acceso a YouTube se guarda de forma segura en las variables del servidor donde corre el bot (Railway) y solo se usa para subir videos y leer estadísticas del propio canal. Las credenciales nunca se comparten ni se publican.

Qué NO se hace con los datos

  • No se comparten datos con terceros.
  • No se venden datos ni se usan para anuncios.
  • No se accede a datos de otros canales ni de otros usuarios.

Retención y eliminación

Los datos se conservan solo mientras la aplicación está en uso. El propietario puede revocar el acceso en cualquier momento desde su cuenta de Google (Seguridad → Acceso de terceros) y eliminar el token del servidor; al hacerlo, la aplicación deja de tener acceso de inmediato.
